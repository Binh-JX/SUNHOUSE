# 🏨 SUNHOUSE Boutique Hotel

A modern, multilingual website for **SUNHOUSE Boutique Hotel** located in Bãi Cháy, Hạ Long, Vietnam. This project showcases hotel facilities, guest rules, operational systems, and provides an immersive digital experience for guests and staff.

## Key Sections:

### Features
- Interactive video gallery (7 themed clips)
- 4-floor virtual tour with photo galleries
- Guest rules in 4 languages (VI, EN, ZH, JA)
- Hotel operations management system
- Staff check-in forms and checklists
- Guest feedback collection

### Technology Stack
- Pure HTML5, CSS3, and Vanilla JavaScript
- No external dependencies
- Responsive design with glassmorphism effects
- Single-page application (SPA)

### Main Pages
1. **Home** - Video player with Ha Long experiences
2. **Hotel Exploration** - 4-floor tours with facilities and rules
3. **Operations** - Guest check-in, staff forms, feedback systems

### Languages
Vietnamese, English, Simplified Chinese, Japanese

### Facilities Documented
- Floor 1: Lobby, Check-in, Elevators
- Floor 2: Common areas, Shared kitchen, Guest rooms
- Floors 3-4: Residential rooms with layouts
